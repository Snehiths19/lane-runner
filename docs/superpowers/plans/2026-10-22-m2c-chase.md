# Slice 2c — Chase Implementation Plan

> **For agentic workers:** TDD (one test → one implementation), pushing after every commit; commit only
> when `npm test` reports `fail 0`.

**Goal:** Stumble on side bumps and edge swipes, crash on a second bump while stumbling, inspector & dog
chasing at a gap that closes on a stumble and catches the runner on a crash.

**Architecture:** New pure module `src/chase.js` holds the stumble timer, run time and the chasers'
gap. `player.js`: `bounceBack` returns whether it started a new bounce; `handleAction` returns `'edge'`
for an edge swipe and starts a short nudge. `main.js` routes both into `bump(chase)` and crashes on
`'crash'`. `world.js` draws two cutouts at the gap.

**Spec:** `docs/superpowers/specs/2026-10-22-m2c-chase-design.md`

## Global Constraints

- Baseline `chase: { stumbleTime, startTime, closeGap, farGap, closeSpeed, dropSpeed, caughtGap, catchTime }`.
- `createChase(rules)` → `{ runTime, stumbleLeft, gap, catching }`; `bump(c, rules)` → `'stumble' | 'crash'`;
  `updateChase(c, dt, rules)`; `startCatch(c)`; `isStumbling(c)`.

## Review Focus

1. **Still touching the same train while bouncing back** must not count as a second bump. → Task 2
   test `bounceBack reports only a new bounce`, Task 4 wiring uses its result.
2. **Second bump after the window ends** is a fresh stumble, not a crash. → Task 1 test.
3. **Edge swipe mid-switch** (left twice quickly from the middle) is a bump, lane unchanged. → Task 3 test.
4. **Catch finishes inside the 1 s crash pause** at any frame rate. → Task 1 test `catch reaches caughtGap within catchTime`.
5. **Pausing** doesn't run the stumble out. → Task 1 test (dt 0 while paused leaves it unchanged; main passes 0).
