# Slice 2b — Trains Implementation Plan

> **For agentic workers:** Execute natively with the `tdd` skill (one test → one implementation),
> pushing after every commit; commit only when `npm test` reports `fail 0`.

**Goal:** Trains with ramps and runnable roofs, roof coins, bounce-back side bumps, surface-following camera.

**Architecture:** Track items gain kind `'ramp'` and a `base` height (roof or ramp surface under a coin).
`ground.js` computes surface height from items by x and distance. `player.js` follows rising surfaces,
falls when they drop, and gains `bounceBack`. `hits.js` treats trains as solid only below the roof and
classifies side vs head-on using the previous frame's distance. World draws ramps and follows surface height.

**Spec:** `docs/superpowers/specs/2026-10-22-m2b-trains-design.md`

## Global Constraints

- New baseline: `track.roofHeight: 3.6`, `track.rampLength` = one row (5). Kind names: `'train'`
  (was `'block'`), `'ramp'`. Item shape `{ id, kind, lane, start, end, base = 0 }`.
- `groundHeightAt(x, distance, items, cfg)` replaces `(lane, distance, items)`; lane = nearest to x.
- Ramp height at d: `roofHeight × (d − start) / (end − start)`.

## Review Focus

1. **Stepping sideways off a roof mid-switch**: falls, doesn't snap or crash. → Task 4 test.
2. **Hopping roof-to-roof**: stays up, no crash from the neighbouring train. → Task 5 test `roof to roof is safe`.
3. **Frame-step head-on misread as side bump at high speed** (2 m steps): front arriving this frame is head-on. → Task 5 test `fast head-on is still a crash`.
4. **Bounce back mid-air / on a roof**: returns to the lane left, keeps height. → Task 3 test.
5. **Old sections with `Bc`** used to be rejected; now roof coins. → Task 2 test replaced deliberately.
